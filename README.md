# QuikA11y - Quick Reference to WCAG Guidelines

**Make accessibility seamless. Reference with confidence.**

QuikA11y is a Figma plugin that provides instant access to WCAG 2.2 guidelines, helping designers and developers make informed accessibility decisions while educating teams about key standards and best practices.

This accessibility plugin helps designers and developers capture references and acceptance criteria for accessible design. Visit [Figma plugin API](https://www.figma.com/plugin-docs/) for Figma plugin API documentation.

## Data Source

This plugin uses a JSON formatted version of WCAG 2.2 data provided by Tenon.io ([WCAG as JSON](https://github.com/tenon-io/wcag-as-json)) and is sourced from the official **WCAG 2.2 documentation** to provide a credible, referenceable source of technical standards for accessibility guidelines.

## Why QuikA11y?

While many accessibility tools exist to check compliance, few focus on *educating* teams about accessibility standards and guidelines. QuikA11y bridges this knowledge gap by making accessibility education effortless, quick, and comprehensive - right within your Figma workflow.

## Features

- **Quick search on WCAG 2.2 guidelines** - Find specific standards instantly
- **Complete WCAG 2.2 reference** - Access all standards and success criteria
- **Key links to essential documents** - Direct access to official WCAG resources
- **Educational rationales** - Understand the *why* behind accessibility decisions
- **Reference notes** - Place accessibility notes directly in your designs
- **Team collaboration** - Share accessibility knowledge with your team
- **Native Figma experience** - Seamless integration with light and dark themes
- **Always up-to-date** - Based on official WCAG 2.2 documentation

## Installation

1. Open Figma
2. Go to Plugins → Browse plugins in Community
3. Search for "QuikA11y"
4. Click "Install"

## How to Use

### Quick Search
1. Open the plugin from the Plugins menu
2. Use the search bar to find specific WCAG guidelines
3. Browse results and click on any guideline for detailed information

### Adding Reference Notes
1. Select an element in your design
2. Open QuikA11y
3. Find the relevant guideline
4. Click "Add Note" to place a reference directly on your design

### Accessing Resources
- Browse the four main WCAG principles: Perceivable, Operable, Understandable, Robust
- Access supporting documents and techniques
- View examples and implementation guidance

## WCAG 2.2 Principles

### Perceivable
Users must be able to perceive all content through sight, sound, or other senses via text alternatives, captions, and flexible layouts.

### Operable
Users must be able to use and navigate all interface elements via keyboard, mouse, or other methods.

### Understandable
Content and interface functions must be clear and predictable for all users.

### Robust
Content must work reliably across different browsers, devices, and assistive technologies like screen readers.
